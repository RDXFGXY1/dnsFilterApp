# Updates and Release Notes

This directory records meaningful application updates. Permanent usage instructions belong in [`../features`](../features/README.md); these files explain what changed in a particular development update.

## Available updates

- [2026-09 — Privacy and Security Suite](2026-09-privacy-security-suite.md)

## Adding a future update

Create a file named `YYYY-MM-short-title.md` with these sections:

```markdown
# Update title

Release date: YYYY-MM-DD

## Added
- New user-visible features.

## Changed
- Important behavior changes.

## Fixed
- Corrected bugs.

## Security notes
- Guarantees, limitations, and migration advice.

## Verification
- Tests or checks performed before release.
```

Add the new file to the **Available updates** list above.
