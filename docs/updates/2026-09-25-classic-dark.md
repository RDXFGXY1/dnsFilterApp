# Classic dark theme

The existing Dark button now uses consistent opaque charcoal surfaces, blue primary actions, readable headings and table headers, and distinct danger/warning/success colors. Coverage includes the DNS bypass assistant, connection freeze, security packs, rule tools and organizer controls.

Select **Dark** in the top toolbar. **Light** restores the original light palette; **System** follows the operating system. The preference remains saved in this browser. No Aurora styling or glass effects are loaded.
