# Focus, Profiles, Schedules, and Learning

## Focus Mode

Starts a timed focus session that applies distraction rules. Sessions can have an intention, protected scope, remaining time, and stop control.

## Doom-scroll Guard

Uses intervention rules, cooldowns, token state, and unlock tracking to reduce repeated access to distracting services. It is a behavioral control, not a clinical tool.

## Screen-Time Bank

Tracks earned tokens and spending for temporary access. It creates a visible tradeoff between focused behavior and discretionary use.

## Wellbeing protection

Combines guard state, tokens, interventions, and unlock history into one area. Its purpose is to avoid scattering related behavior controls across settings.

## Network Profiles

Saves a complete named protection mode and allows preview before application. Profiles can represent Study, Gaming, Banking, Public Wi-Fi, Privacy, or another user-defined state.

## App Schedules

Blocks one Windows executable during selected weekdays and time ranges. Overnight ranges are supported. Removing an active schedule also removes its firewall rule.

## Learning Mode

Observes one application for a bounded period and builds a local destination baseline. The user reviews evidence before converting observations into trust.

## Automatic destination response

Evaluates unseen destinations on a repeating interval. Supported policy levels include review and whole-application blocking, with quarantine support in the underlying security workflow. High-impact automation should begin in review mode.

## Windows notification filters

Controls whether new destinations create desktop notifications, the minimum risk, and optional application filters. Existing alerts are not replayed merely because notification settings change.

## Connection Freeze

Keeps existing network sessions and refuses new outbound connections across IPv4 and IPv6. It can run for a duration or until manually stopped. DNS Filter and required local traffic remain available; application behavior may degrade when a new connection is required.

## Emergency Lockdown

Temporarily blocks DNS access except for an explicit emergency allowlist. It expires automatically and is designed for incident containment, not routine browsing.
