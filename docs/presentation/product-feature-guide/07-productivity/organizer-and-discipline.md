# Organizer and Discipline

## Dashboard Todo List

Creates todos and nested subtodos with completion state, priority, editing, search, sorting, and deletion. Completing a parent can complete its children according to the implemented behavior.

### YAML import and export

Validates YAML before import, supports add/replace modes, exports the current hierarchy, and reports imported or skipped items.

## Notes

Creates, edits, searches, and deletes local notes from the dashboard. The editor uses a focused workspace rather than mixing editing controls into the list.

## Discipline workspace

Discipline is a separate personal command system sharing the same local service and authentication.

### Command Center

Shows execution score, overdue work, open loops, work in progress, blocked items, recommended next actions, and a focus timer.

### Today

Creates a realistic daily plan, tracks committed and completed missions, highlights overdue items, and shows daily momentum.

### Home

Summarizes tasks, projects, completion, streaks, activity, priority distribution, and active-project progress.

### Goals

Creates goals, links projects, tracks progress, and marks completion.

### Calendar and timetable

Shows dated work plus a weekly timetable for recurring commitments, breaks, and focus blocks.

### Projects

Organizes tasks into projects, tracks progress, dependencies, milestones, risk, activity, and portfolio-level analytics.

### Habits and reminders

Tracks recurring check-ins, streaks, reminder state, and upcoming commitments.

### Planning intelligence

Detects overdue, blocked, unscheduled, unestimated, overloaded, stalled, and oversized work. It calculates a focus queue and critical-path guidance.

### Analytics and activity

Provides completion trends, heatmaps, workload, priorities, project movement, and event history.

## Boundary from security features

Productivity data remains usable while the configuration vault is locked. Vault protection is reserved for security and configuration changes, not ordinary personal task edits.
