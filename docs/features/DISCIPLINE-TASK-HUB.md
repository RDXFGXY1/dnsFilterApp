# Discipline Task Hub

The Task Hub is the execution layer between goals, projects, focus sessions,
calendar planning, and reviews. It stores its data locally in the main DNS
Filter database.

## Included workflow

1. Daily planning through My Day and the existing Command Center ranking.
2. Persistent task time blocks plus the calendar and weekly timetable.
3. Task breakdown into nested executable steps and checklists.
4. Energy-aware filtering and recommendations.
5. Focus-session distraction and activity review.
6. Optional protection profile activation before focusing on a task.
7. End-of-day shutdown that clears completed commitments and can move unfinished work to tomorrow.
8. Weekly execution review in Command Center.
9. My Day commitment capacity and overload warnings.
10. Recovery mode for overdue work.
11. Reusable task templates with checklists.
12. Explicit Waiting state with the person or prerequisite recorded.
13. Completion evidence such as a result, link, path, or commit.
14. Task reminders with in-app and browser notifications while Discipline is open.
15. Estimate accuracy, workload, deadline, waiting, and planning analytics.

Tasks also support projects, priorities, tags, due dates, recurrence, reminders,
estimates, actual time, notes, subtasks, dependencies in project planning, and a
direct Start Focus action. Completing a recurring task creates its next local
occurrence. Templates and every new planning field survive service restarts.

The Task Hub does not call an AI service. Discipline Intelligence will be added
as a separate opt-in layer after the local task workflow is established.
