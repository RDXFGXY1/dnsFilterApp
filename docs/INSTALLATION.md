# Installation

The canonical installation, update, uninstall, and recovery guide is
[INSTALL-WINDOWS-LINUX.md](../INSTALL-WINDOWS-LINUX.md).

Current official targets:

- Windows 11 x64.
- Arch Linux and Arch-based distributions on x64 or ARM64.

Other Linux distributions and macOS are not official targets in this phase. Do
not use old generic installers as evidence that their native controls are supported.

For Arch real-machine validation, also read
[ARCH-TEST-CHECKLIST.md](ARCH-TEST-CHECKLIST.md).
