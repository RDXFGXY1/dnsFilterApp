# v0.2.0 — Release draft

Status: **draft, not published**. The executable version remains `0.1.0` until
the release is built and checked. This page compares the current working tree
with GitHub `main` at `7174d23` (2026-10-14), verified before the source
update was published.

For the itemized change list, see [Unreleased changes after v0.1.0](UNRELEASED.md).

## What changes for users

| Area | v0.1.0 baseline | Current development tree |
|---|---|---|
| Extensibility | Plugin Center | Side Apps can be imported as `.adnf` packages and opened from the main dashboard. |
| Windows startup | Installed background service | Startup mode can run DNS filtering before sign-in and check resolver health separately. |
| Vault recovery | Saved offline recovery code | Adds one-time email codes via configurable SMTP and removable-USB recovery codes. |
| Dashboard access | Local dashboard | Adds a user-configured local hostname and allowlisted LAN devices; Internet access is pending. |
| Discipline | Tasks, projects, focus, reminders | Adds Needs Attention and a time-based rescue plan. |
| DNS visibility | Live activity and analytics | Keeps the latest 200 Live entries, top blocked domains, and DNS health events. |
| Network Test | Quick and Full on-demand tests | Adds custom data/time limits, clearer results, and a 30-result history. |

## Added since the baseline

- **Side Apps:** install independent `.adnf` packages from the dashboard's Side
  Apps menu. Each package owns its HTML, CSS, JavaScript, and data; Focus OS is
  an example. See [the package guide](../SIDE-APPS.md).
- **Windows operation:** background startup can run before sign-in, with an
  independent DNS fallback check. The desktop app adds a tray icon and Windows
  notifications for deadlines. See [startup](../WINDOWS-STARTUP.md) and
  [notifications](../WINDOWS-NOTIFICATIONS.md).
- **Dashboard and recovery:** configurable local dashboard host, guarded LAN
  access, Vault unlock controls, SMTP recovery codes, and USB recovery material.
- **Discipline:** Needs Attention combines overdue work and reminders with a
  short rescue plan; tasks and projects received further workspace controls.
- **Network visibility:** the latest 200 Live DNS entries survive a page reload,
  the dashboard shows top blocked domains and a DNS health timeline, and Network
  Test saves the latest 30 results for comparison.
- **Network Test controls:** Quick and Full presets plus a custom total data
  budget of 5–500 MB or a timed test of 5–60 seconds.
- **Privacy:** Live history can be limited by retention period, client IP can be
  hidden, and blocked-only storage can be selected.

The existing v0.1.0 features, including DNS rules, Connection Freeze, Plugin
Center, and Focus Capsules, remain part of the product. They are not listed as
new features in this draft.

## Changed and fixed

- Windows DNS startup and local listener behavior were hardened for machines
  where another service occupies the wildcard DNS port.
- Dashboard sign-in and Vault flows were repaired; recovery email now uses a
  styled HTML message.
- Network Test results use clearer metric displays and a history comparison.
- The Windows CLI and emergency DNS restore path were expanded. See
  [Windows installation](../installation/windows/README.md).

## Release checks still required

1. Complete the Windows portable build, release audit, and a fresh install and
   update test. Recheck Windows startup after an actual reboot.
2. Verify the dashboard features in the packaged build. Test SMTP delivery
   with user-supplied settings.
3. Sign the official Windows release binaries and scripts with an Authenticode
   certificate; none was available in the development environment.
4. Move finalized entries from [UNRELEASED](UNRELEASED.md), update the
   executable version, and replace this draft with `v0.2.0.md` when the release
   is ready.

Internet access from other networks is still a placeholder; do not advertise
remote Internet access as part of this release.
