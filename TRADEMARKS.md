# DNSFilter — Trademark & Branding Policy

## 1. Overview

DNSFilter is a free and open-source DNS filtering application licensed under the GNU General Public License v3.0 (GPL-3.0).

This policy explains how the DNSFilter project name, official logo, and visual identity may be used.

Our goal is to protect the identity of the original project while encouraging open-source development, contributions, and independent forks.

## 2. Source Code and Branding

The DNSFilter source code is governed by the GPL-3.0 license.

The GPL-3.0 permits users to use, study, modify, and redistribute the software under its terms.

The software license does not grant additional trademark rights to the DNSFilter name, logo, or branding.

This policy does not override the GPL-3.0 or restrict rights provided by applicable law.

## 3. Permitted Uses

You may, without requesting permission:

- Mention DNSFilter in articles, tutorials, documentation, reviews, and discussions.
- Identify your project as being based on or compatible with DNSFilter, provided the relationship is accurately described.
- Link to the official DNSFilter repository.
- Use the DNSFilter name for truthful attribution, without implying official endorsement.
- Create and distribute forks in accordance with the GPL-3.0.

## 4. Uses Requiring Permission

Please request permission before:

- Using the official DNSFilter logo as the primary branding of an independent product.
- Presenting an unofficial or modified distribution as an official DNSFilter release.
- Using DNSFilter branding in a manner likely to cause confusion about the source, sponsorship, or endorsement of a product.
- Using official project branding in promotional materials that imply an affiliation or endorsement that does not exist.

## 5. Forks and Modified Versions

We welcome forks and independent development.

Forks may identify themselves as being based on DNSFilter. However, independent distributions should adopt distinguishable branding where necessary to prevent confusion with official releases.

For example:

**Acceptable:** "ExampleDNS — Based on DNSFilter"

**Potentially misleading:** "Official DNSFilter Pro" when the product is not affiliated with the original project.

These guidelines do not prevent truthful references or other uses permitted by law.
