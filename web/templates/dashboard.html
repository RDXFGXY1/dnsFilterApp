Windows Startup

Run DNS Filter in the background without opening a terminal. Your saved filtering rules and local DNS routing preference are used.

Checking…

An independent Windows task checks once a minute. If the local resolver stops answering, it temporarily restores automatic DNS. Filtering resumes when the server returns and local DNS routing is enabled. Traffic is unfiltered during fallback.

Before sign-in runs as a system task, without your Windows password. After sign-in starts after any user logs in. Mode changes take effect at the next Windows startup; saving does not stop the current server.
